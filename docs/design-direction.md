# Design Direction — Serene Origins

## Design goal
Create a premium, emotionally safe website that feels modern and credible without feeling sterile or overly clinical.

## Overall vibe
- quiet luxury
- restrained wellness
- modern editorial
- soft tech
- premium support experience

## Visual keywords
- calm
- elevated
- private
- intentional
- spacious
- discreet
- grounded
- refined

## Recommended color direction
Use a dark, premium base with soft warm neutrals and a subtle accent.

### Suggested palette inspiration
- deep charcoal / near-black background
- muted stone / warm gray surfaces
- soft cream or off-white text on dark sections
- restrained sage, muted gold, dusty mauve, or calm teal as accent options

Do not use:
- loud medical blues
- neon wellness colors
- harsh gradients
- overly feminine clichés unless intentionally balanced

## Typography direction
Use a refined, readable font pairing.
The typography should feel:
- premium
- calm
- modern
- strong on mobile

### Typography behavior
- large clean hero
- elegant section headings
- readable body width
- strong spacing rhythm
- limited font count

## Layout direction
- generous whitespace
- section contrast
- cards with soft borders or glass effect if subtle
- rounded corners used with restraint
- clean CTA hierarchy
- trust conveyed through order and clarity

## Motion direction
Use subtle animation only:
- fade / slight rise on section reveal
- gentle hover states
- no flashy movement
- no distracting parallax

## Imagery direction
Imagery should feel discreet and emotionally intelligent.

Prefer:
- abstract texture
- atmospheric gradients
- close-cropped lifestyle details
- protected / private feeling visuals

Avoid:
- obvious medical imagery
- generic smiling stock support groups
- cliché wellness stock photography

## UI components to prioritize
- premium hero CTA block
- system cards
- feature list
- step-by-step onboarding row
- pricing card
- FAQ accordion
- footer with legal links

## Mobile requirements
The mobile experience should feel elite:
- strong headline wrapping
- no cramped cards
- sticky CTA optional if done tastefully
- tap targets large enough
- frictionless scroll flow

## Presentation standard
The site should feel like something a founder, operator, or investor can look at and immediately say:
“This is real. This is focused. This is ready.”
